# NatureCollection

My first Android app, written in Kotlin while following Graven's Android tutorial: a small plant collection backed by Firebase.

## What it does
- Home screen with a horizontal carousel and a vertical list of plants, loaded from Firebase Realtime Database.
- Plant detail popup with description, growth and watering needs; mark a plant as a favorite or delete it.
- A collection screen showing favorite plants.
- An add-plant form that uploads a photo to Firebase Storage.

## Tech stack
Kotlin, Android SDK (min 21, target 33), RecyclerView, Glide, Firebase Realtime Database and Storage, Gradle.

## Context
Built in May 2023 by following the tutorial; it was my first Android project, not original work.
